# i-Moovie · Frontend

Aplicación web de un cine hecha con **React** (Vite + react-router-dom). Es solo frontend: los datos son simulados y se guardan en el navegador.

## Cómo correrlo

```bash
npm install     # una sola vez
npm run dev     # abrir http://localhost:5173
```

Otros comandos: `npm run build` (versión final) y `npm run lint` (revisión de código).
